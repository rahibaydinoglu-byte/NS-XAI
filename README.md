# NS-XAI: net-sustainability assessment of explainable AI models for energy systems

Code and results for the manuscript

> R. Imamguluyev, *Net-sustainability assessment of explainable AI models for energy systems: a fuzzy benefit–cost framework with break-even scale analysis and a load-forecasting case study* (submitted to *Sustainable Computing: Informatics and Systems*, 2026).

The repository reproduces every number, table and figure of the case study: day-ahead hourly load forecasting for Spain (ENTSO-E, 2015–2018) with seven models (ridge, TSK-8, TSK-32, LightGBM, MLP, LSTM, Transformer), measured CPU time of hyper-parameter search, training, inference and explanation, hourly carbon intensity, the fuzzy SBCR / break-even-scale / possibility–necessity analysis, and the statistical tests.

## Contents

| Path | Content |
|---|---|
| `code/common.py` | data loading, features, splits, models (incl. first-order TSK neuro-fuzzy), CPU-time meter |
| `code/run_models.py` | hyper-parameter search, 5-seed training, inference cost, robustness — one model per call |
| `code/run_xai.py` | explanation cost and explanation stability (exact linear, TreeSHAP, expected-gradients SHAP, intrinsic TSK) |
| `code/analysis.py` | carbon intensity, fuzzy energy/carbon accounting, fuzzy SBCR, break-even scale, Π/N, Pareto, IBCR, Friedman / HLN-DM / Wilcoxon, carbon-aware scheduling, sensitivity |
| `code/figures.py`, `code/fig_framework.py` | Figures 1–5 |
| `results/` | Task A outputs (forecasting from history; reference = seasonal naive) |
| `results_B/` | Task B outputs (correction of the TSO day-ahead forecast; reference = TSO forecast) |
| `figures/` | figures as used in the manuscript |
| `data/` | place `energy_dataset.csv` here (see below) |

Fitted model files (`model_*.pkl`) are not included; they are regenerated by `run_models.py`. The test-set predictions of all seeds (`pred_*.npz`) are included, so `analysis.py` and `figures.py` can be re-run without retraining.

## Data

`energy_dataset.csv` (ENTSO-E Transparency Platform data for Spain, 2015–2018) as redistributed with the darts library:

```bash
curl -L -o data/energy_dataset.csv https://raw.githubusercontent.com/unit8co/darts/master/datasets/energy_dataset.csv
```

## Environment

Experiments were run on a 2-vCPU Intel Xeon (2.8 GHz) container without GPU, Python 3.13, PyTorch 2.5.1 (CPU, 2 threads). See `requirements.txt`. The container exposed no power telemetry; energy is therefore derived from measured process CPU time and the fuzzy power model of the paper (Table 3). CPU times depend on hardware, so re-runs on other machines will reproduce the accuracy results exactly up to library-level nondeterminism, and the cost results up to a hardware-dependent factor.

## Reproduction

```bash
pip install -r requirements.txt
bash run_all.sh          # full run: ~2–3 h on 2 CPU cores (LSTM dominates)
# or only the analysis on the included predictions/costs:
cd code && python analysis.py && TASK=B python analysis.py && python figures.py
```

Main outputs: `results*/summary.json` (statistics, Pareto sets, IBCR, scheduling), `results*/table_models.csv` (accuracy, CPU time, energy, emissions, L*), `results*/table_sbcr.csv` and `table_sbcr_host.csv` (fuzzy SBCR and Π/N by scale for boundaries B0 and B1), `results*/table_tests.csv`, `results*/table_sensitivity.csv`.

## Declared assumptions

Per-core power (4, 8, 15) W; PUE (1.1, 1.2, 1.6); fossil share of balancing energy (0.05, 0.25, 0.60); balancing emission factor (0.41, 0.49, 0.65) tCO2e/MWh (IPCC gas CC min/median/max); host power (2, 5, 15) W; monthly retraining, 365 forecast issues per year, one explanation per issue. All are set at the top of the relevant sections of `code/analysis.py`.
